1. 通用信息

本工具提供多种与 MIFARE Classic RFID 标签交互的核心功能。它专为对 MIFARE Classic 技术具备基本了解的用户设计。 由于所有数据的输入和输出均采用十六进制，您需要对十六进制数制有基本的理解。

重要提示：
  • 本应用无法破解或破解任何 MIFARE Classic 密钥。在读取或写入 RFID 标签前，您必须先拥有该标签对应扇区的密钥（参见“新手入门”章节）。
  • 本应用不具备也不提供“暴力破解”功能，因为在 NFC 射频协议交互限制下，暴力破解速度极其缓慢，完全不切实际。
  • 部分手机因硬件 NFC 控制芯片（例如部分博通 Broadcom 芯片）不支持 MIFARE Classic 专有协议而无法读取 MFC 标签。

1.1 功能特性

  • 读取 MIFARE Classic 标签数据
  • 保存、编辑和分享读取到的转储（Dump）数据
  • 向 MIFARE Classic 标签写入数据（按块写入）
  • 克隆 MIFARE Classic 标签（将转储写入另一张已知密钥的标签）
  • 基于字典攻击机制的密钥映射管理
  • 将标签格式化恢复为出厂默认状态
  • 向特殊后门卡（Magic Card Gen2）写入厂商块（块 0 / UID）
  • 创建、编辑、保存与分享密钥字典文件（.keys）
  • 解码与编码值块（Value Blocks）与访问条件（Access Conditions）
  • 展示标签芯片详细参数与硬件架构
  • 以语法高亮十六进制或 7-bit US-ASCII 展现转储
  • 计算 UID 校验和（BCC）
  • 支持导入/导出 Proxmark、libnfc 等多种格式转储与 ZIP 备份

1.2 数据存储

MCT 将转储和密钥文件存储在应用内部安全私有目录中。其他应用或电脑 USB 无法直接访问这些私有文件。 如需导出使用，可通过界面的“分享”功能或 导入 / 导出工具 备份至公共存储。

注意：卸载本应用将永久清除内部所有转储和密钥文件，卸载前请务必使用“导出/备份”导出 ZIP！

2. 新手入门

读取标签首先需要知道该标签各扇区的密钥。得益于 MIFARE Classic 算法历史上的设计缺陷， 您可以借助 Proxmark3、Chameleon 或配有特殊软件（mfcuk, mfoc）的电脑读卡器获取完整 A/B 密钥。

应用内置了 std.keys、extended-std.keys 和 hotel-std.keys 常见默认字典。 您可以新建自己的密钥文件，将每行 12 位十六进制密钥录入其中。

字典映射机制优势： 您无需预先知道哪个密钥属于哪个扇区。MCT 会自动用字典中的所有密钥依次认证每个扇区，并最大限度读出已知密钥对应的全部数据！

3. 读取标签

读取流程分为两步：

  1. 选择密钥文件与扇区范围：点击主界面的“读标签”，勾选包含该卡密钥的字典文件，并可选择仅读取部分扇区范围。
  2. 贴卡读取：启动映射后将卡片贴在手机 NFC 天线区域。MCT 认证成功后会自动完整读取扇区数据并展示在转储编辑器中。

4. 写入标签

安全警告：向某些特定控制块（例如扇区尾块中的 Access Conditions）写入错误数据可能会导致扇区永久不可逆锁定！请在完全清楚操作含义的前提下谨慎写入。

4.1 写块

指定扇区编号和块编号（例如 1K 标签的扇区 0–15，块 0–3），输入 16 字节（32 位）十六进制数据，并选择具备写权限的密钥文件进行单块写入。

4.2 写转储 (克隆)

将先前保存的完整转储镜像克隆写入另一张目标卡片中。应用会在写入前自动做一致性校验，若检测到“块只读”或“写密钥未知”，将提前给出提示。

厂商块写入（UID 克隆）：普通原装卡片的块 0 是只读硬编码的。只有支持直接写命令的特殊“魔术卡（Magic Card Gen2 / CUID）”才能被写入块 0 以克隆 UID。

4.3 工厂格式化

尝试将标签所有扇区恢复为出厂交付状态（数据块清零 0x00，扇区尾块重置为默认密钥 FFFFFFFFFFFF 与访问条件 FF078000）。

4.4 增 / 减值块

支持对符合电子钱包格式的值块（Value Block）执行自增、自减并提交传输。

4.5 转移与恢复值块

利用 MIFARE Classic 的 Transfer 与 Restore 指令，配合暂存块绕过仅允许扣款（Decrement-only）的权限限制。

5. 编辑 / 分析转储文件

转储编辑器是具有语法高亮与分析功能的专业十六进制编辑器：

  • 分享转储：导出为标准 MCT 转储文本发送至其他应用或邮箱。
  • 显示为 ASCII：将数据块转换展示为 7-bit US-ASCII 可见文本。
  • 解析访问控制条件：将扇区尾块的 3 字节访问位表格化解析为可读权限矩阵（读/写/增/减权限）。
  • 值块解码：将符合规范的值块直接换算为 32 位有符号整数。
  • 制造日期解析：解析块 0 厂商块后 2 字节包含的 BCD 生产年份与周次。
  • 差异比对与提取密钥：直接从编辑器跳入比对工具或快速提取有效密钥生成新字典。

6. 编辑或添加密钥文件

密钥文件是纯文本文件，每行包含一个 6 字节（12 个十六进制字符）密钥。以 # 开头的行将被视为注释忽略。编辑器支持快速去除重复密钥。

7. 工具箱

7.1 标签信息

显示当前贴附卡片的芯片架构信息、UID、ATQA、SAK、ATS 及内存布局。

7.2 值块编解码器

在十进制整数、取反备份值、块地址与 16 字节标准值块格式之间进行双向编解码。

7.3 访问条件编解码器

可视化编辑扇区尾块与各数据块的读写密钥要求，并自动计算出准确的 3 字节 Access Bits。

7.4 差异比对工具

高亮对比两个转储文件，逐字节清晰标识出数据差异位置。

7.5 BCC 校验码计算器

为 4 字节单倍 UID 计算块 0 第 5 字节所需的异或校验字节（BCC）。

7.6 UID 克隆工具

快速复制卡片 UID，并自动为 Gen2 兼容卡片计算组装合法的块 0 数据。

7.7 导入 / 导出 / 备份

支持 .mct、.keys、.bin、.dump、.eml、.json 文件的相互转换及整包 ZIP 备份。

7.8 数据格式转换

提供 ASCII、十六进制与二进制之间的快速互转。

7.9 UID 日志

记录历史读取标签的 UID、时间戳，支持一键复制与快速分享。

8. 外部 NFC 读卡器

支持通过 OTG USB 配合 External NFC 服务连接外置读卡器（如 ACR 122U、PN532、MFRC522）进行读写。
